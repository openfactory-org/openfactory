# Code of Conduct

Open Factory adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct. Read the full text at that link.

It applies to every project space: the repository, issues, pull requests, discussions and any event where you represent the project.

## Report a problem

Report unacceptable behavior privately to the maintainers. Use [GitHub private vulnerability reporting](https://github.com/openfactory-org/openfactory/security/advisories/new) and start the title with `Code of conduct:`. Only the maintainers can read the report. Do not report conduct problems in public issues or discussions.

The maintainers keep the identity of the reporter confidential.

## Enforcement

The maintainers review each report and decide on an action. They follow the enforcement guidelines of the Contributor Covenant 2.1:

| Level | Example behavior | Action |
|---|---|---|
| Correction | Unprofessional or unwelcome language | A private written warning |
| Warning | A single violation, or a series of them | A warning, and no interaction with the people involved for a period |
| Temporary ban | A serious violation, or continued inappropriate behavior | No interaction or public communication with the project for a period |
| Permanent ban | A pattern of violations, harassment, or aggression toward a group | No public interaction with the project |

A maintainer who is involved in a report does not take part in the decision.

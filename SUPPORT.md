# Support

| You want to | Go to |
|---|---|
| Ask a question or share an idea | [GitHub Discussions](https://github.com/openfactory-org/openfactory/discussions) |
| Report a bug | [A new bug report](https://github.com/openfactory-org/openfactory/issues/new?template=bug_report.yml) |
| Request a feature | [A new feature request](https://github.com/openfactory-org/openfactory/issues/new?template=feature_request.yml) |
| Report a security problem | The private process in [SECURITY.md](SECURITY.md). Do not open a public issue. |

Before you ask:

1. Read the [documentation](docs/README.md) and [Troubleshooting](docs/troubleshooting.md).
2. Search the existing issues and discussions.

When you ask, give the Open Factory version (`openfactory version` and the control plane version from `GET /api/v1/version`), the sandbox provider or worker that you use, and the logs with secrets removed.

Support is from the community and the maintainers, on a best-effort basis. There is no guaranteed response time.

The master key is in the Secret {{ include "openfactory.keySecretName" . }}. Back it up:

1. Wait until the server is ready, then create the first team, admin and API
   key (one time):

   kubectl -n {{ .Release.Namespace }} rollout status {{ include "openfactory.serverKind" . | lower }}/{{ include "openfactory.fullname" . }}

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "openfactory.fullname" . }} 8080:{{ .Values.server.service.port }}
   curl -s -X POST http://localhost:8080/api/v1/bootstrap \
     -H 'Content-Type: application/json' \
     -d '{"team_name":"Acme","admin_email":"admin@example.com","admin_name":"Admin"}'

   Store the returned API key. It is shown once.

2. Open the dashboard at {{ if or .Values.server.publicURL .Values.ingress.enabled }}{{ include "openfactory.publicURL" . }}{{ else }}http://localhost:8080 (through the port-forward){{ end }} and
{{- if .Values.oidc.enabled }} sign in with {{ .Values.oidc.displayName }}
   (redirect URI: {{ default (printf "%s/auth/oidc/callback" (include "openfactory.publicURL" .)) .Values.oidc.redirectURL }}).
{{- else }} sign in with the
   API key.
{{- end }}
